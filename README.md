An entry for [Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11) on make.fun: one funny fortune cookie line for an AI agent, a single line of at most 140 characters.

## How it works

`main.py` writes a single line to `/output/entry.txt`. The program is fully
deterministic — it produces byte-identical output on every run.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
